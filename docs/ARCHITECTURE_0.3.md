# Application Architecture 0.3

This file documents the historical 0.3 application line of ESP32 Davis Weather Gateway.

The current architecture is documented in [`ARCHITECTURE_0.4.md`](ARCHITECTURE_0.4.md).

The 0.3 line introduced the local Web dashboard, OLED integration, MQTT, BME280 improvements, AS3935 support and extended Davis diagnostics while keeping the Davis EU 868 MHz FHSS receiver as the authoritative weather RF engine.

For current service ordering, microSD storage, compressed Web UI and remote-access preparation, use the 0.4 architecture document.
